## M2.1a 实施规划（2026-11-03）

目标：交付可实际使用的只读文件/Git 工作台，作为 DESK-007 的第一个子检查点。Renderer 只使用项目 ID 和 Host 签发的范围绑定、不透明条目 ID，不能提交绝对路径、Git argv 或 Shell。工作区身份由既有 Store 核对；文件与 Git 读取在独立只读、无网络、空白 Home 的受限进程执行，不继承认证或父客户端工具桥。

本点支持有界目录浏览、UTF-8 文本/二进制/大文件说明、普通仓库状态、暂存与未暂存的分文件 Diff，以及路径/身份/外部修改拒绝。保护本地运行缓存、认证配置与 Git 内部文件；拒绝符号链接扩权。Git 使用固定 argv，禁止外部 Diff、textconv、fsmonitor/hooks 和过滤器执行，不读用户全局 Git 配置。第一版仅开放工作区根内真实 `.git` 目录的普通仓库；Linked Worktree、子目录 Git 元数据授权、子模块与写操作另行交付，不悄悄扩大读取范围。

本点不修改工作区文件，不提供暂存/提交/推送/清理或 PTY stdin。后续写操作需接入持久 Operation/Intent、Workspace 写租约与真实结果；清理必须检查未跟踪、忽略文件和本地独有提交，Git 状态干净不代表可以安全删除。

实现与用例并行覆盖：真实 Git 暂存/未暂存/未跟踪/重命名、路径含空格与前导选项字符、外部 Git 程序禁用、跨项目/伪造/过期条目、目录替换、符号链接、保护文件、二进制及有界输出。组件用例与真实 OS 沙箱阻断/真实 Electron 界面分别记录；此点不请求模型，不以合成 Git 数据或静态界面当作原生验收。常规入口 `pnpm check`，新增能力必须保持 Electron 沙箱与白名单 IPC。未来进展点仍只保留验证要求，具体用例到实现时再细化。
