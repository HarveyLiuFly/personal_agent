## M3.1a 开发规划（2026-11-03）

提供真实可使用的主聊天入口，先完成客户端稳定 Message ID/Hash 去重、确定性只读任务查询、用户明确建立的 Focus 和歧义澄清。消息/Decision/QUERY_TASK Operation/Task Link/Focus 或 Pending 同一事务保存；不新建聊天任务库。显式 UI Task ID 优先，状态查询可引用已有 Task 或有效 Focus，多个候选需用明确 Pending ID + 候选 Task 回答；目标版本/范围/删除代重新校验。后台结果不自行改 Focus，旧 Focus Revision 冲突拒绝，不自动改用最新对象。

本点不运行模型聊天、结构化模型 Router 或任务控制，也不启动真实 Run/Intent。自由文本可作为讨论记录保存，说明尚未连接模型；暂停/取消等动作不能借选中对象变成隐式执行。查询读取授权 Registry 而不是启动执行器，不依赖工作区当前可访问；Project/Task/消息的 Dot/墓碑范围依然检查。界面显示历史查询快照时间，任务详细工具流仍在项目任务页。

具体用例随实现覆盖消息重复/冲突、跨项目/外来 ID、Focus CAS、显式对象和动作区别、同名歧义、多个 Pending/过期/目标已变、纯文本/有界输出、Task/消息墓碑、源目录不可用以及真实 SQLite/Electron 重开。subagent 单独负责纯路由与用例，主 Agent 负责同库事务、DTO/IPC/UI/真实桌面和整合；不并行写同一实现文件。常规 pnpm check，真实模型 Smoke 留待接入模型路由/执行切片后单独验收，M3 Gate 不因本点关闭。


## M3.1a 执行与验收（2026-11-03）

状态：首个开发切片完成，定位 `checkpoint/M3.1a`。Schema 6 不变，新增固定 readMainChat/submitMainChat 两项 API，总计 **47 项**。同一 SQLite 的 Message/Decision/QUERY_TASK/Task Link/Focus/Pending 原子提交，不新建 Task Store，不产生模型 Run/Intent。一个 Dot 的 Conversation/Focus 共用，当前聊天视图按项目过滤，不宣称已交付跨项目全量主聊天或完整 Context Builder。

客户端稳定 Message ID/规范输入 Hash 去重先于 Focus CAS：相同消息只读取原结果，内容冲突拒绝，重发不把后来 Focus 改回。只读 Registry 查询绑定当时 Task Version，原 Task 状态/版本不变；Scope/墓碑在 Host 检查，源目录消失仍能查元数据，文件与执行入口原物理校验保留。支持 /query、/note 和保守中英文状态查询，UI明确对象 > 明确文本 ID > 有效 Focus > 唯一标题；同名、未知/冲突引用、非查询动作澄清，未知普通文本保存讨论记录并注明无模型回答。选中 Task 不能把“取消”变成查询或执行。

多 Pending 按 ID/项目/目标版本/有效期重验，仅解决选定问题；15 分钟过期后转 expired。用户明确查询才建立 Focus，后台任务不改 Focus。消息/Task 删除标记隐藏关联快照与 Focus，不宣称已完成 M3 遗忘 Gate。近期消息/候选/文本数量有界并显示裁剪，原文保留；UI查询结果带时间且说明是上次状态。模态面板保留底层工作台草稿，选择 Pending 保留另一条未发送聊天草稿；同名候选显示短 ID 区分。未确认保存使用原 ID 核对，候选或 Focus 变化不自动重发。
